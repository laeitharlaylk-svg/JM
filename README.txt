JM SOLUTION - Android Project

App name: JM SOLUTION
Package: com.jmsolution.app
Version: 1.0

The For I love website is bundled inside the APK as app/src/main/assets/index.html.
No internet connection is required for the page itself.

BUILD APK IN ANDROID STUDIO
1. Extract this ZIP.
2. Open the JM_SOLUTION_Android_Project folder in Android Studio.
3. Let Gradle sync finish.
4. Choose Build > Build App Bundle(s) / APK(s) > Build APK(s).
5. The debug APK will normally be created under:
   app/build/outputs/apk/debug/app-debug.apk

For a release APK, use:
Build > Generate Signed App Bundle or APK > APK

Note:
Android/Chrome may require a user tap before audible media starts.
The page already starts the background music when the "For You" button is tapped.
